# 鑑識版規格

離線簽名比對的鑑識輔助工具。本文件定義要做什麼、為什麼這樣做，以及明確不做什麼。

- **狀態**：已實作（`features.py` / `train.py` / `validate.py` / `forensic_app.py` + `forensic.html`）
- **對象**：實作者，以及需要檢視方法的鑑識人員
- **教學版**（`app.py`，已完成）不受本規格影響，繼續留在 port 8000

---

## 1. 目標與取捨

協助文書鑑識人員檢視待鑑簽名與已知樣本的差異，並讓每一個輸出數字都能拆回具體、具名的特徵。

**可解釋性優先於準確率。** 結論要寫進報告、要能在法庭上被質問，所以不用神經網路。已知的代價：在 CEDAR 上手工特徵的 EER 是 15.1%，深度特徵是 6.7%。

**工具不下結論。** 輸出證據強度，由鑑識人員判斷。這既符合 ENFSI 的評估框架，也避免「自動化結論」在法庭上的問題。

---

## 2. 系統結構

```
兩張簽名圖
  → 前處理（與教學版共用）
  → 8 族特徵，約 3330 維
  → 差值向量：各維取絕對差，再除以 σ
  → Elastic Net 線性模型 → 原始分數
  → 邏輯迴歸校準 → likelihood ratio
  → ENFSI 風格文字級距
```

### 為什麼是差值向量加單一線性模型

這個做法在文獻上稱為 dichotomy transformation。它把「這是誰的簽名」轉換成「這兩張是不是同一人寫的」，用所有人的資料訓練**一個**模型。

- 相對於「每人一個 SVM」：新使用者不必重新訓練，也不需要當事人的負樣本。
- 相對於目前教學版的距離門檻：權重是學出來的，而不是所有維度等權重。這是準確率的主要來源。
- 相對於非線性模型：線性模型的分數等於 `Σ 權重ᵢ × 差異ᵢ`，可以精確拆解。**這是選線性的唯一理由，也是不可退讓的條件。**

## 3. 特徵（8 族，約 3330 維）

| 族 | 維度 | 內容 | 個別維度具名 |
|---|---|---|---|
| 幾何 | 7 | 寬高比、墨跡密度、質心水平／垂直位置、整體傾角、筆畫段數、筆畫總長÷高度 | 是 |
| 方向性筆畫分布 | 10 | 骨架切線方向 8 箱，加端點數、交叉點數 | 是 |
| 小波子帶能量 | 10 | 3 層分解，各子帶能量 | 是 |
| Radon 投影 | 36 | 每 5 度一個角度的投影能量 | 是 |
| GLCM | 48 | 2 個距離 × 4 個角度 × 6 個統計量 | 是 |
| HOG | 2970 | 15×22 格 × 9 個方向 | 否，改用熱區圖 |
| LBP | 250 | 5×5 格 × 10 種模式 | 否 |
| SIFT 配對 | 3 | 配對率、配對點平均描述子距離、通過仿射 RANSAC 的比例 | 是 |

### 前處理（與教學版共用）

裁到筆跡外框（取 0.5%～99.5% 分位數再外擴 3%）、等比縮放到固定框、Otsu 二值化、刪除 20 px 以下雜點。

幾何與方向特徵在正規化後的原圖上計算；HOG 與 LBP 在置中到畫布並縮放成 150×220 的圖上計算，這樣格子才對得起來。

### 實作時的偏離

**方向分布沒有用 Freeman 鏈碼。** 鏈碼的角度來自 8 鄰居的位移，能取到的角度只有少數幾種：
以兩個鄰居的連線定義走向時，67.5°–90° 與 157.5°–180° 這兩個區間結構上永遠取不到值，
等於有兩個恆為零的維度。改用「視窗內骨架點座標的共變異數主軸」，角度是連續的，8 箱都有值。

**SIFT 關鍵點上限 600 個。** 全存 2640 張的描述子會讓快取膨脹到 GB 級，
以固定種子抽樣到 600 個，配對率的分母也跟著一致。

**貢獻拆解需要基準。** 差值向量取的是絕對差，貢獻 = 權重 × 絕對差 的符號完全由權重決定，
長條會全部朝同一邊。改以「同源配對的典型差異」為基準：

```
分數 = Σ 權重ᵢ × (xᵢ − 基準ᵢ) + (截距 + Σ 權重ᵢ × 基準ᵢ)
```

這是精確的代數重寫，不是事後編的解釋。差得比一般人自己簽名時還小 → 支持同一人；
差得更多 → 支持不同人。基準存在模型檔的 `baseline_diff`。

### SIFT 的特殊性

SIFT 是配對式方法，不像其他族能各自算出一個向量，它直接產生「兩張圖之間」的數字，所以是差值向量裡唯一不做相減的維度。

第三個維度（幾何一致性）特別重要：熟練偽造常見的模式是「局部像、整體比例錯」，會表現為「配對數多但通不過幾何檢驗」，單看配對數抓不到。

## 4. σ 策略

σ 是「一個人重複簽自己名字時，這個特徵正常會變動多少」，用來把單位不同的特徵換算成可比較的尺度。

依已知樣本數混合族群 σ 與當事人自己的 σ：

| 已知樣本數 | 行為 |
|---|---|
| < 3 | 拒絕計算，說明原因 |
| 3 – 9 | 使用族群 σ，畫面標示「個人變化範圍樣本不足」 |
| ≥ 10 | 混入當事人自己的 σ，畫面顯示混合比例 |

**目前用哪一種必須顯示在畫面上。** 鑑識人員被問到「這個 σ 是誰的變化範圍」時要答得出來，而答案隨案件樣本數而不同。

## 5. 多張已知樣本的處理

每張已知樣本各算一次分數與 LR，**全部列出**，另給平均當標題數字。

離散程度本身就是資訊：待鑑簽名若和 5 張已知樣本中的 4 張都像、只和 1 張差很多，可能是那張已知樣本本身異常，鑑識人員需要看到這件事。

實作上，標題數字取「各張分數的平均」。因為模型是線性的，這在數學上等於「差值向量取平均後算一次分數」
（`Σwᵢxᵢ` 的平均 = 平均後的 `Σwᵢx̄ᵢ`），所以 validate.py 用後者加速，數值完全相同。
逐張的分數與 LR 仍照算並回傳（`perSpecimen`），只是 UI 定案時把那張表移除了。

## 6. 訓練與校準

### 資料切分（CEDAR 55 位寫者）

| 用途 | 寫者 | 內容 |
|---|---|---|
| 訓練 | 31 – 48（18 人） | 約 5400 組配對 |
| 校準 | 49 – 55（7 人） | 只用來把分數映射成 LR |
| 評估 | 1 – 30（30 人） | 每人 3 張參考簽名 |

**同一位寫者的配對不得跨越切分。** 換成其他資料集時必須維持這個原則。

### 配對取樣（每位訓練寫者）

| 類型 | 組數 | 說明 |
|---|---|---|
| 正樣本 | 120 | 同一人的兩張真簽名 |
| 熟練偽造 | 120 | 該人的真簽名對上針對該人的偽造 |
| 隨機不同人 | 60 | 該人的真簽名對上其他人的真簽名 |

熟練偽造與隨機不同人的比例約 2:1，因為鑑識案件幾乎都是刻意模仿，隨機冒充在實務上很少見。

### 模型

Elastic Net。強度與 L1 比例用**以寫者為單位的分組交叉驗證**在訓練集上挑選；隨機切分會讓同一寫者的配對落在兩邊，高估效果。

選 Elastic Net 而非 L1 的理由：全加之後有多族在量重疊的東西（Radon 對上幾何傾角與 HOG 方向、GLCM 對上 LBP）。L1 會在相關特徵中任意挑一個、其餘歸零，換一批訓練資料就換一組「重要特徵」，這在法庭上是致命的。Elastic Net 會讓相關的一組特徵一起保留並分攤權重。

### 校準

邏輯迴歸，把原始分數映射為對數 LR。**校準必須使用模型沒見過的寫者**，否則分數偏樂觀，LR 會系統性偏大——這是 LR 系統最常見的失效方式。

## 7. 驗證（`validate.py`，每個模型版本跑一次）

| 產出 | 說明 |
|---|---|
| Cllr | 對數 LR 成本，同時罰「方向錯」與「過度自信」。鑑識領域評估 LR 系統的標準指標，不是 EER |
| Tippett 圖 | 分別畫出同源與異源樣本的 LR 分布 |
| 消融表 | 逐族拿掉，看 Cllr 變化 |

**Cllr 與 Tippett 圖一律分開報兩組**：熟練偽造一組、隨機不同人一組。兩者混算會被容易分辨的隨機組把數字拉漂亮，掩蓋熟練偽造的真實難度。

消融表的用途是讓「8 族全加」這個決定變成可驗證的：某族拿掉後 Cllr 沒變壞，它在報告裡就是純負擔，應該砍掉。

摘要（Cllr、驗證資料、日期）寫進模型權重檔，由頁面顯示。

## 8. 介面（`forensic_app.py` + `forensic.html`，port 8010）

### 輸入

已知樣本（多張）、待鑑簽名（一張）。

一次只比對一份待鑑簽名。不做多份並列，因為那會誘發一個統計陷阱：多份各自算 LR 之後很容易被誤以為可以相乘，但它們往往來自同一書寫事件、彼此不獨立，相乘會嚴重高估。若日後要做，畫面必須明確標示「各份獨立評估，不可相乘」。

### 輸出

使用者在 UI 定案時移除了兩個區塊：**逐張已知樣本的表格**（後端仍回傳 `perSpecimen`，未顯示）
與**關鍵點對應圖**（SIFT 仍計算 3 維特徵並列入族貢獻，只是不畫連線圖）。
熱區的編號標註也改為滑鼠停留顯示貢獻值。

| 區塊 | 內容 |
|---|---|
| 證據強度 | LR 數值 + 文字級距。LR 接近 1 時明確寫「本次檢驗無法區分」。**不給二元判定** |
| 族貢獻 | 8 族的**帶正負號**貢獻長條圖（權重 × 差異） |
| 具名特徵 | 貢獻最大的 10 個具名特徵 |
| 熱區圖 | 見下 |
| SIFT 對應點圖 | 兩圖之間的對應連線，並標出「參考有、待鑑找不到對應」的位置 |
| 觀測值表 | 逐特徵的本人平均、待鑑值；「偏離幾個 σ」放在滑鼠停留提示裡 |
| 出處與警語 | σ 來源、模型驗證摘要、原型數字警語 |

帶正負號很重要：支持同一人與支持不同人的觀察會同時存在，而教學版的距離只能顯示「差多少」，看不出哪些觀察其實是支持同一人的。

### 熱區圖

每格把 9 個方向的「權重 × 差異」加總，畫成帶正負號的貢獻熱區：

- 雙色漸層（藍↔紅），中點透明，**透明度隨絕對值變化**，貢獻接近 0 的區域完全透明
- 上下限對稱（`vmin = -vmax`）並在 99 百分位截斷
- 格子用最近鄰，不插值
- 色階條標明兩個方向各代表什麼，不只靠顏色
- 與未標註的原圖並排
- 貢獻最大的 5～8 格標上編號，旁邊列出對應文字說明，與具名特徵表互相參照

編號標註是為了報告：鑑識報告的傳統是在兩張圖上標編號逐點討論，熱區適合螢幕上找位置，但編號才能配文字說明。

**畫面上只有一種判定依據。** 不同時呈現「偏離熱區」與「貢獻熱區」；教學版的 ±2σ 灰色帶在鑑識版要拿掉，因為某特徵偏離 3σ 但權重低時，影響可能小於偏離 1σ 但權重高的特徵。

### 匯出

單一 HTML 檔，內嵌上傳的簽名影像、所有圖表、觀測值表、族與具名特徵貢獻、LR 與級距、模型驗證摘要、警語。

由瀏覽器端組出並直接下載。**伺服器端只將上傳影像寫入暫存資料夾，運算後即刪，不保留任何簽名影像。** 匯出檔含個人資料，存放位置、加密與保存期限依使用單位規範決定。

## 9. 文字級距

預設採 ENFSI 風格，**寫成可調的設定**：

| LR | 用語 |
|---|---|
| 1 – 10 | 稍微支持 |
| 10 – 100 | 中度支持 |
| 100 – 1000 | 強烈支持 |
| > 1000 | 非常強烈支持 |
| 接近 1 | 本次檢驗無法區分 |

反方向（支持不同人）同理。若使用單位有既定的結論用語，應改用該用語——鑑識報告的措辭通常有機構規範，工具不該自己發明一套。

## 12. 風險

| 風險 | 說明 |
|---|---|
| **資料集與案件不符** | CEDAR 是西方拉丁字母簽名。中文簽名的筆畫數、結構、提筆次數分布都不同，σ、權重、LR 全部不適用，必須換資料重估。**這是最高風險項** |
| **校準寫者僅 7 位** | LR 絕對數值不穩定。這是 CEDAR 只有 55 位寫者的硬限制。擴充資料時應優先增加**寫者人數**，而非每人的簽名張數 |
| **權重清單可能不穩** | 多族量測重疊，Elastic Net 雖會分攤權重，換資料後排序仍可能改變。消融表用於監測此事 |
| **準確率未必優於教學版** | 學習權重通常明顯進步，但新增的幾族有可能只是雜訊，須待消融表驗證 |
| **離線方法的先天限制** | 看不到筆順、速度、筆壓，而這些是分辨刻意模仿的關鍵線索 |

### 一次性計算成本

SIFT 抽特徵 0.47 秒／張 × 2640 張 ≈ 21 分鐘，加上配對比對，合計約 30 分鐘，之後快取。每個案件的即時計算約 2 秒。

## 14. 實作順序

1. `features.py`：抽出共用前處理與特徵，加上新增的 5 族（方向分布、小波、Radon、GLCM、SIFT），建快取
2. `train.py`：配對取樣、Elastic Net、校準，輸出權重檔
3. `validate.py`：Cllr、Tippett 圖、消融表
4. `forensic_app.py` + `forensic.html`：頁面與匯出
